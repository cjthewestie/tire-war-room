# SOP-EV-01 異常事件處置總則與權限分級

- 文件編號：SOP-EV-01
- 適用範圍：戰情室所有異常事件（事件偵測喚醒事件指揮官之後的流程）
- 權責單位：主管（核准）、事件指揮官（AI，只提方案）、安全核心（規則）
- 版本：v1.0〔示範版〕

## 1. 目的
規定異常事件從偵測到結案的流程，以及哪些動作可以自動、哪些需要人核准。

## 2. 流程
分類 → 規劃 → 模擬 → 把關 → 執行 → 驗證 → 結案；驗證未達預期就換假設重排；連續失敗則安全停止（保留原排程）。
1. 事件偵測（時序異常預測，非 LLM）常駐運行，1 分鐘內發現異常；壞資料不喚醒 AI。
2. 安全核心（PLC 規則）先行：煉膠 ≥120°C 停、已加硫 ≥110°C 停、硫化機低於 120°C 保壓；不等 AI。
3. 事件指揮官讀取感測器、SOP、訂單班表，提出假設與步驟；物理與排程數值由公式與求解器計算，不由 AI 推測。
4. 工具失敗重試 1 次，仍失敗改走 SOP 路徑；求解器逾時改用備援求解器；連續 2 次失敗則保留原排程並安全停止。

## 3. 風險分級
- R0：讀取與計算（讀感測器、異常預測、硫化公式、排程求解、SOP 查詢、訂單班表查詢），自動執行。
- R1：通知維修、資訊通知，自動執行（顯示「已自動」）。
- R2：設定硫化時間建議值、確認新排程、夜班加班，需主管核准。
- R3：放慢或暫停投料、跨組調人、機台停用，需主管核准並記錄選項與理由。
- 不在白名單的動作一律攔截並寫入稽核日誌；系統沒有任何直接寫入 PLC 或致動器的權限。

## 4. 核准
主管在手機（廠內區網）核准、修改或拒絕；決定回到狀態機。排程保留前一版，可一鍵回滾。

## 5. 紀錄
狀態轉換、工具呼叫、核准與理由全部寫入只能追加的稽核日誌。
