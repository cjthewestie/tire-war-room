# SOP-MX-01 密煉機異常處置

- 文件編號：SOP-MX-01
- 適用範圍：A 線、B 線密煉機（混煉）
- 權責單位：胎體／胎面膠組（A 線）、胎側膠組（B 線）、維修組、品管
- 版本：v1.0〔示範版〕

## 1. 目的
密煉機是每批膠料的起點，排膠溫度、混煉時間或轉子電流異常會讓整批膠料物性不合格。本程序規定異常時的判定與處置。

## 2. 觸發條件
1. 排膠溫度超過配方上限（未加硫母煉膠示範上限 115°C）。
2. 混煉時間超過標準 ±20%。
3. 轉子電流或上頂栓壓力異常波動、冷卻水流量偏低。
4. 加料順序或稱量錯誤警示。

## 3. 處置步驟
1. 排膠溫度偏高：檢查轉子與混煉室冷卻水（SOP-CW-01），降低轉速一段。
2. 混煉時間異常：該批標記為待驗，取樣送品管做門尼黏度與焦燒時間試驗（QC 取樣試驗）。
3. 轉子電流異常：停止加料，通知維修檢查減速機與軸封；不可在負載中強行重啟。
4. 已加硫化劑的終煉膠：溫度超過 110°C 時安全核心直接停機（焦燒防護），該批扣留。
5. 未加硫的母煉膠：溫度 ≥120°C 安全核心直接停機。
6. 判定該批是否可回用：由品管依試驗結果決定，可回用者降級摻用比例不得超過 10%。

## 4. 判定門檻
- 煉膠停機 ≥120°C；已加硫停機 ≥110°C（安全核心）。
- 門尼黏度超出規格 ±5：不合格。

## 5. 權責與核准
- 通知維修：自動。
- 該批報廢或降級：品管判定、主管核准。

## 6. 紀錄
記錄批號、配方、排膠溫度、混煉時間、試驗結果與判定。
