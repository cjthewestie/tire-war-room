# SOP-SN-01 感測器漂移判定

- 文件編號：SOP-SN-01
- 適用範圍：全廠 28 台機台的溫度、壓力、水流、蒸汽壓感測器
- 權責單位：維修組（儀電）、事件偵測系統、各機台班組
- 版本：v1.0〔示範版〕

## 1. 目的
感測器漂移會讓系統誤判異常、或漏判真正的異常。本程序規定如何分辨「製程真的變了」和「讀數壞了」，壞資料不喚醒 AI。

## 2. 觸發條件
1. 單點讀數跳動超過物理可能（例：硫化機 1 秒內溫度變化超過 5°C）。
2. 讀數長時間完全不變（凍結超過 10 分鐘）。
3. 雙測溫點相差超過門檻（開煉機 5°C、硫化機 3°C）。
4. 同管線或同產線其他機台正常，只有一台讀數持續偏移。

## 3. 處置步驟
1. 資料驗證層先過濾：超出量程、跳變、凍結、缺值的讀數標記為壞資料，不喚醒指揮官。
2. 交叉比對：
   - 硫化機：對照同一蒸汽集管其他機台（例：7 號機對照 6、8 號機），並比對該機蒸汽壓與液壓。蒸汽壓正常、同管線溫度正常、只有本機溫度下降 → 傾向感測器漂移或本機洩漏。
   - 開煉機：比對第二測溫點與手持紅外線溫度計。
3. 現場以標準溫度計校驗：差異超過 2°C 判定為漂移。
4. 判定漂移時：該感測器標記離線，改用備援點；若無備援，機台改人工每 15 分鐘巡檢一次直到更換。
5. 無法判定是漂移還是真實洩漏時，以安全為先：視為真實異常處置（SOP-CP-01）。

## 4. 判定門檻
- 校驗誤差 ≤1°C：正常；1～2°C：觀察；>2°C：漂移，更換或校正。
- 安全核心依規則動作時不等待漂移判定。

## 5. 權責與核准
- 感測器離線與更換：維修組執行，班長確認。
- 因漂移造成的停機、復機：依 SOP-SD-01。

## 6. 紀錄
記錄感測器編號、比對對象、校驗值、處置與更換時間。
