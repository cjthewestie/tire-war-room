# SOP-MT-01 原料短缺與補料處置

- 文件編號：SOP-MT-01
- 適用範圍：原料倉（天然橡膠、合成橡膠、碳黑、硫化劑、鋼絲、尼龍布）與 A～D 各線投料；缺料、斷料、原料不足、待補料的訂單
- 權責單位：生管（排程、補料）、採購（供應商、在途進貨）、倉儲（收貨、發料）、品管（進料檢驗）
- 版本：v0.1〔示範用草稿，待廠方確認〕

## 概要
原料存量掉到再訂購點以下，或在途進貨延遲、進料檢驗不合格，都會讓某條線缺料、斷料。本程序規定怎麼判斷缺料會不會影響今天的模次與交期、怎麼補料、怎麼調整排程。數值取自戰情室模擬工廠的原料設定（例：尼龍布存量 180 m、再訂購點 160 m、每次訂 400 m、交期 96 小時、D 線裁切每小時用 3 m），為示範用草稿，待廠方確認。

## 1. 目的
缺料時先保住已在生產與硫化中的胎，再依交期決定哪張訂單先用剩下的料；補料與重排都要留下紀錄，避免同一批料被兩條線重複排用。

## 2. 觸發條件
1. 原料庫存狀態變成「該補貨」（存量 ≤ 再訂購點）、「偏低」（≤ 再訂購點一半）或「缺料」（存量 0）。
2. 在途進貨狀態變成「延遲」，或預計到貨晚於存量用完的時間（例：尼龍布剩 180 m、每小時用 3 m，約 60 小時用完，但採購交期 96 小時）。
3. 進料檢驗不合格，該批原料整批不能用（等同斷料）。
4. 訂單的胎停在「待補料」，或工單因原料不足無法發料。

## 3. 處置步驟
1. 查原料庫存：每種原料的存量、還能用幾天、是否該補貨、在途數量與預計到貨時間。
2. 判斷影響範圍：哪條線、哪台機用這種原料（尼龍布 → D 線裁切；鋼絲 → C 線；橡膠、碳黑、硫化劑 → A／B 線密煉），哪些訂單的胎會停在待補料。
3. 已在硫化中的胎不受影響，照原排程出模；只調整尚未投料的模次。
4. 存量撐不到到貨：
   - 通知採購向供應商確認到貨時間，必要時申請急件或分批交貨。
   - 依交期排序，剩下的料先給交期最近的訂單；其他訂單改排或延後。
   - 有替代規格或替代料時，須經品管同意才能使用。
5. 交排程求解器重排受影響的模次，確認新的入模、出模時刻有人上班，再擬計劃送主管核准。
6. 料到貨後：倉儲收貨、品管進料檢驗合格，才把待補料的胎改回備料中並恢復投料。

## 4. 判定門檻
- 存量 ≤ 再訂購點：自動開採購單（補料），列入當日交接。
- 存量 ≤ 再訂購點一半，或預計用完時間早於在途到貨：視為缺料風險，啟動本程序第 4 步。
- 存量 0 或進料檢驗不合格：該線停止投料，受影響訂單交期重新評估。
- 預估延誤超過 4 小時或影響任一訂單交期：需主管核准重排。

## 5. 權責與核准
- 查庫存、通知採購與倉儲：自動（R1）。
- 重排模次、改用替代料、延後訂單交期：需主管核准。
- 替代料使用：需品管核准。

## 6. 紀錄
記錄缺料原料、存量、在途數量與預計到貨、受影響的線與訂單、補料單號、重排結果與核准人。
